# fonts

`diablo.woff2` / `diablo.woff` / `diablo.ttf` — **Diablo Heavy**, MaGiK Enterprises,
dated 1-23-97 in its own version string. A fan-made face cut in the shape of the
Diablo logo: barred `T`, slashed `O`, slashed zero.

It is **not** Exocet, the typeface the games actually used — that one is a
commercial release by Emigre and would have to be licensed to be used here.

This file carries no embedded licence or trademark field, so its redistribution
terms are unstated rather than known-free. It is used here on a private wedding
page. If this site is ever reused for anything commercial, replace it — the
nearest properly-licensed substitutes are Uncial Antiqua (closest in spirit) or
UnifrakturMaguntia (blackletter), both on Google Fonts.

`diablo.woff2` is what the page loads; the `.woff` is a fallback for browsers too
old for woff2, and the `.ttf` is the original the other two were converted from.
